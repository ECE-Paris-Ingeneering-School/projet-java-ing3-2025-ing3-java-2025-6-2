Le but de ce thème "Shopping" du projet Java est d'écrire une application de commande d'articles qui permettra au client d'acheter des articles. L'application aidera également la compagnie de Shopping à conserver et mettre à jour ses dossiers de vente et de clients.

L'application doit permettre au(x) client(s) de chercher (filtrer) des articles selon plusieurs critères : catégories, prix, dates, type. Chaque article doit renseigner un certain nombre d’informations : le nom, le prix, des photos, les avis et commentaires des utilisateurs, un descriptif des caractéristiques proposées. Vous devez créer un écran factice pour indiquer le traitement des paiements.

Les clients peuvent être de deux types les nouveaux clients ou anciens clients :
- Les nouveaux clients devront s'inscrire avec un identifiant et un mot de passe.
- Les anciens clients auront déjà un identifiant et un mot de passe pour se connecter. Ces anciens clients pourront réserver les billets avec réduction offerte en fonction de l’offre de réduction. Mais les nouveaux clients n’auront aucune réduction offerte.

Le client doit pouvoir choisir et commander un article avec un moyen de paiement. Parmi les articles proposés, il doit pouvoir filtrer selon plusieurs critères. Il doit pouvoir visualiser les caractéristiques, les avis, le prix ou encore des visuels

Cette application doit être développée pour les deux types d'utilisateurs suivants avec un certain nombre de fonctionnalités pour chacun de ces utilisateurs :

1. Clients : rechercher et réserver des articles, calculer et visualiser la facture des articles commandés avec/sans réductions, naviguer dans la disponibilité des articles, etc.

2. Administrateurs de l’application : mettre à jour les articles actuellement disponibles, introduire diverses offres de réduction pour les anciens clients, maintenir les dossiers des clients, etc.
